#+title: CV + Publications Build Pipeline
#+author: Diego Zamboni

This repository builds my CV and publications in multiple formats, and publishes them under =/vita/= on my website. The pipeline is JSON Resume + custom theme for HTML, Typst for the CV PDF, and LaTeX for the publications PDF.

* Overview

- *Source of truth*: =zamboni-vita.json= (JSON Resume).
- *HTML CV*: rendered with the local theme in =themes/jsonresume-theme-even=.
- *CV PDF*: generated via Typst from JSON Resume (see =scripts/render_typst_cv.py=).
- *Publications HTML*: generated from BibTeX using =scripts/build_publications.py= + =templates/publications.html.j2=.
- *Publications PDF*: built via LaTeX from =pubs-src/zamboni-pubs.tex= using Tectonic.
- *Outputs*: under =build/zamboni-jsonresume/{dev,prod}/vita/=

The site structure is:
- =/vita/= → HTML CV
- =/vita/publications/= → publications HTML
- =/vita/zamboni-vita.pdf= → CV PDF
- =/vita/publications/zamboni-pubs.pdf= → publications PDF
- =/vita/publications/zamboni-pubs.bib= → aggregated BibTeX (for download)

* Repo Layout

- =zamboni-vita.json=: JSON Resume source.
- =pubs-src/=: publications LaTeX and BibTeX sources (e.g., =zamboni-pubs.tex=, =*.bib=).
- =scripts/=: build helpers (JSON Resume render, Typst render, pubs build, etc.).
- =templates/=: Jinja2 templates for publications HTML and Typst.
- =themes/=: local JSON Resume theme.
- =build/=: generated outputs (dev/prod).

* Setup

You can spin up a [[https://code.visualstudio.com/docs/devcontainers/containers][devcontainer]] with all the necessary dependencies like this:

#+begin_src sh
mise dev-up
#+end_src

Once the container is up, use =mise dev-bash= to open a shell inside the container.

If you want to develop outside the container, install dependencies once (this happens automatically within the container):

#+begin_src sh
mise run bootstrap
#+end_src

* Build Commands

Dev builds (HTML + PDFs):

#+begin_src sh
mise run build-dev
#+end_src

Prod builds:

#+begin_src sh
mise run build-prod
#+end_src

One-command dev loop (serve + watch):

#+begin_src sh
mise run go-dev
#+end_src

* Publications PDF (LaTeX)

The publications PDF is built from =pubs-src/zamboni-pubs.tex= using this exact command (run in =pubs-src=) (required LaTeX to be installed separately to get the correct version of biblatex.sty, which Tectonic is missing):

#+begin_src sh
tectonic -Z search-path=$(dirname $(kpsewhich biblatex.sty)) zamboni-pubs.tex
#+end_src

The =mise= tasks =pubs-pdf-dev= / =pubs-pdf-prod= run this and copy the resulting PDF into the site output directory.

* Aggregated BibTeX Output

=build_publications.py= writes an aggregated =zamboni-pubs.bib= into the output directory, grouped by section with comment headers. This is the file exposed at =/vita/publications/zamboni-pubs.bib=.

* Floating Links

Both the CV HTML and the publications HTML use floating action icons (bottom-right). These are configured in:

- CV: =zamboni-vita.json= → =meta.themeOptions.links=
- Publications: top of =templates/publications.html.j2= (default list). Defined in =mise.toml= in the =pubs_links= variable.

* Deploy

Deploy the production output to the website:

#+begin_src sh
mise run deploy-prod
#+end_src

This rebuilds prod and syncs =build/zamboni-jsonresume/prod/vita/= to =../websites/zzamboni.org/static/vita/= (excluding =*.typ= files).

* Updating CV Publication Reference Numbers

If the publication ordering changes, update reference numbers in =zamboni-vita.json= using:

#+begin_src sh
python scripts/update_pub_numbers.py
#+end_src

This matches publication IDs in the HTML against the JSON references and updates the numeric labels accordingly.
